# 图传模拟视频目录 (`videos/`)

将任意待播放的视频文件放入本目录后，模拟服务器会自动扫描并循环编码为 **HEVC (H.265 Annex-B)** 流，通过 `UDP :3334` 推送给自定义客户端。

- 支持常见封装格式：`.mp4`、`.mkv`、`.mov`、`.avi`、`.ts`、`.webm`、`.flv`、`.m4v`、`.mpg`、`.mpeg`
- 支持裸流格式：`.hevc`、`.h265`、`.265`
- 放入或移除视频后，服务端会在 **1.5 秒内自动识别** 并开始循环轮播（无需重启）；也可在 Web 控制台「图传媒体库」中切换目录、刷新列表或点选指定文件播放。
